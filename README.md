# Gemini File Search デモアプリケーション

株式会社フィールフロウ - 生成AI技術検証プロジェクト

## 概要

Googleが発表したGemini APIの新機能「File Search」を実装・検証するための最小限のデモアプリケーションです。
本デモは、文書ファイルをアップロードし、その内容に基づいて質問応答を行う機能を提供します。

## 参考記事

https://blog.google/technology/developers/file-search-gemini-api/

## 主な機能

- ファイルアップロード（PDF、TXT、DOC、DOCX対応）
- アップロードしたファイルの内容に対する自然言語質問
- Gemini APIを使用したリアルタイム回答生成

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. Gemini APIキーの取得

1. [Google AI Studio](https://makersuite.google.com/app/apikey) にアクセス
2. APIキーを生成
3. アプリケーション起動後、UIから入力

### 3. アプリケーションの起動

```bash
npm start
```

ブラウザで `http://localhost:3000` が自動的に開きます。

## 使用方法

### ステップ1: APIキー設定
- 取得したGemini APIキーを入力フィールドに貼り付け

### ステップ2: ファイルアップロード
- 「ファイルを選択」ボタンからテスト用ファイルを選択
- 「ファイルをアップロード」ボタンをクリック

### ステップ3: 質問入力
- アップロードしたファイルに関する質問を入力
- 「質問する」ボタンをクリック

## 技術スタック

- **フロントエンド**: React 18
- **AI SDK**: @google/genai (Google GenAI SDK v1.29.0)
- **モデル**: gemini-2.5-flash

> **注意**: 旧SDK `@google/generative-ai` は2025年8月31日にサポート終了となるため、新しい `@google/genai` を使用しています。

## マーケティング視点での検証ポイント

### 1. 技術的な優位性
- **処理速度**: ファイルアップロードから回答生成までの時間
- **精度**: ファイル内容の理解度と回答の正確性
- **対応ファイル形式**: 実際に動作するファイルタイプの範囲

### 2. ビジネスユースケース
- **契約書分析**: 法務文書の要点抽出
- **レポート要約**: 長文レポートの自動要約
- **技術文書検索**: マニュアルやドキュメントからの情報検索
- **議事録分析**: 会議記録からのアクションアイテム抽出

### 3. 競合比較
- **OpenAI File Search** との比較
- **Claude Code Interpreter** との比較
- **処理コスト**: APIコストの計測

### 4. UX/UI評価
- **操作の簡便性**: エンドユーザーの学習コスト
- **エラーハンドリング**: エラー時の対応とフィードバック
- **レスポンス時間**: ユーザー体験への影響

## テスト用サンプルファイル

以下のようなファイルでテストすることを推奨:

1. **短い文書（1-2ページ）**: 基本的な理解度の確認
2. **技術文書**: 専門用語の認識精度
3. **構造化文書**: 表やリストの理解度
4. **複数言語**: 日本語文書の処理精度
